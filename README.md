# Python Basics

## Introduction
Python is a high-level programming language that is widely used for various applications such as web development, data analysis, artificial intelligence, scientific computing, and more. This document provides an overview of the basics of Python programming.

## 1. Variables and Data Types
Python supports various data types including integers, floats, strings, and booleans. Here are some examples:

```python
# Example of variable assignment
name = 'John'
age = 30
height = 5.9
is_student = False
```

## 2. Control Structures
Python includes various control structures such as if statements, loops, etc.

### If Statements
```python
if age > 18:
    print("Adult")
else:
    print("Minor")
```

### For Loop
```python
for i in range(5):
    print(i)
```

## 3. Functions
Functions are reusable pieces of code that perform a specific task.

```python
def greet(name):
    return f"Hello, {name}!"

print(greet('Alice'))
```

## 4. Lists
Lists are used to store multiple items in a single variable.

```python
fruits = ["apple", "banana", "cherry"]
print(fruits[0])  # Output: apple
```

## 5. Dictionaries
Dictionaries store data in key-value pairs.

```python
person = {"name": "John", "age": 30}
print(person["name"])  # Output: John
```
