Python pre začiatočníkov

Stránka na učenie Pythonu s inštaláciou, základmi, vstavanými modulmi a 30 otázkovým testom.

Inštalácia Základy Moduly Test

1. Inštalácia VS Code

Windows

  1. Stiahni si VS Code z code.visualstudio.com.
  2. Spusti inštalátor a vyber "Add to PATH".
  3. Nainštaluj rozšírenie Python od Microsoft.

Linux

  1. Inštaluj pomocou balíčka pre distribúciu alebo Snap: sudo snap install --classic code.
  2. Otvor VS Code a nainštaluj rozšírenie Python.
  3. Skontroluj Python: python3 --version.

iPad

  1. Stiahni appku VS Code z App Store (ak je k dispozícii) alebo alternativu ako Pyto.
  2. Použi cloudové služby, napr. GitHub Codespaces alebo VS Code Web.
  3. Pracuj s jednoduchými skriptmi a ukladanie na cloud.

2. Základy Python

Prvý program

Najjednoduchší Python program vypíše text na obrazovku.

print("Ahoj, Python!")

Premenné a dátové typy

Python používa premenné bez explicitného typu.

meno = "Anna"
vek = 25
vyska = 1.72
je_programator = True
print(meno, vek, vyska, je_programator)

Základné príkazy

Podmienky, cykly a funkcie takto vyzerajú v Pythone.

cislo = 10
if cislo > 5:
    print("Veľké číslo")
else:
    print("Malé číslo")

for i in range(3):
    print(i)

while cislo > 0:
    print(cislo)
    cislo -= 1


def pozdrav(meno):
    return f"Ahoj, {meno}!"

print(pozdrav("Marek"))

Funkcie a moduly

Funkcie pomáhajú organizovať opakujúci sa kód.

import math

def obvod_kruhu(r):
    return 2 * math.pi * r

print(obvod_kruhu(5))

3. Vstavané moduly

math

Matematické funkcie a konštanty.

import math
print(math.sqrt(16))
print(math.pi)

os

Práca so súborovým systémom.

import os
print(os.getcwd())
print(os.listdir('.'))

sys

Integrácia s interpreterom Pythonu.

import sys
print(sys.version)
print(sys.platform)

random

Generovanie náhodných čísel.

import random
print(random.randint(1, 10))
print(random.choice(["jablko", "banán", "hruška"]))

datetime

Práca s dátumom a časom.

from datetime import datetime
now = datetime.now()
print(now.strftime("%Y-%m-%d %H:%M:%S"))
